Printable chore chart

Names down the side, days across the top, and a box to tick or sticker. Weekly blocks stack down the sheet, which is the shape that actually works on a fridge door.

Open the maker Free · no sign-up · nothing uploaded

What you can change

  • Several weeks on one sheet, so it lasts a month
  • Square, circle or star boxes — stars if stickers are involved
  • Alternate-row shading so eyes track the right line
  • An optional total or reward column

Printing it correctly

Choose Print, then pick Save as PDF as the destination if you want a file. Set scale to 100% and margins to None — the sheet already carries its exact paper size, so the browser must not rescale it. Anything else and the dimensions you chose are no longer the dimensions on the page.

Questions

Can I use it for one child?

Yes — put chores in the list instead of names.
