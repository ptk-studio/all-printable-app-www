Printable dot grid paper

Bullet-journal dots at true spacing, in the size your notebook actually is. The usual reason to print your own is that you want A5 or a planner insert rather than Letter, and that is exactly what most sites will not give you.

What you can change

  • True 5 mm spacing by default, or any value you like
  • Adjustable dot size, and a larger dot every 4, 5 or 6
  • A5, Pocket, Personal and Classic insert sizes built in
  • Ink-saver mode for a lighter sheet

Printing it correctly

Choose Print, then pick Save as PDF as the destination if you want a file. Set scale to 100% and margins to None — the sheet already carries its exact paper size, so the browser must not rescale it. Anything else and the dimensions you chose are no longer the dimensions on the page.

Questions

Which spacing do bullet journals use?

Usually 5 mm. That is the default here.

Can I print it on planner inserts?

Yes — Classic, A5, Personal and Pocket are all available.
