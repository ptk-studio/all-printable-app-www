Printable handwriting practice paper

Guide lines for learning to write, with a dashed or dotted midline and an optional descender guide. Type a name or a word and it prints as hollow outlines to trace, repeated along each line.

Printing it correctly

Choose Print, then pick Save as PDF as the destination if you want a file. Set scale to 100% and margins to None — the sheet already carries its exact paper size, so the browser must not rescale it. Anything else and the dimensions you chose are no longer the dimensions on the page.

Questions

Why does the tracing stop before the right edge?

It stops short deliberately rather than risk cutting a word in half, and leaves room to write the word again unaided.
