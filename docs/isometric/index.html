Printable isometric paper

A triangular lattice for drawing in three dimensions — lines at 30° and 150° with optional verticals, at the spacing you choose.

What you can change

  • Set the spacing in millimetres or inches

  • Prints up to A2 and 24 × 36 in for larger drawings

Printing it correctly

Choose Print, then pick Save as PDF as the destination if you want a file. Set scale to 100% and margins to None — the sheet already carries its exact paper size, so the browser must not rescale it. Anything else and the dimensions you chose are no longer the dimensions on the page.

Questions

Is this the same as triangle paper?

Yes — isometric paper is the triangular grid used for 3D sketching.
