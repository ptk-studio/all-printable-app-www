# Landing pages

Status: **live** — generated by `tools/build-landing.mjs` into `docs/<slug>/`

One indexable page per printable, at its own URL: `/graph-paper/`,
`/times-tables/`, `/flashcards/`. Before this, a single home page was carrying
all the search weight for 26 printables that people look for by name.

## The failure mode this had to avoid

Twenty-six pages spun from one template, differing only in a noun, are
**doorway pages**. Search engines identify and demote them, so the naive
version of this feature is worse than not doing it.

So the copy is authored per printable in `tools/landing-copy.js`, and each
entry has to say something true and specific about *that* sheet — the actual
7.1 mm college rule, the duplex flip geometry, the 43-to-25 clue range. The
rule of thumb: if an entry has nothing particular to say, it should not have a
page.

Checked rather than assumed: across the 26 pages there are **zero duplicate
intros and zero bullet points reused between pages** (104 bullets, all
distinct).

## Structure

Breadcrumb, H1 matching the phrase people search, a specific intro, "what you
can change", an at-a-glance spec table, the print-at-100% instruction, two or
three real questions, sibling links within the category, and a call to action
at the top and bottom. Plus a `WebApplication` JSON-LD block and a canonical
link.

## Generation, not a build step

The site is still buildless to serve and deploy. `tools/build-landing.mjs` is a
maintenance tool whose **output is committed**; nothing runs at request time.
Re-run it after editing the registry or the copy:

```sh
node tools/build-landing.mjs
```

It also rewrites `docs/sitemap.xml` — home, the seven makers, and all 26
landing pages.

## How they link together

Home cards use the stretched-link pattern: the card title covers the tile and
opens the printable's page, while a separate "Open the maker" link goes
straight into the generator with the right preset. Two crawlable links per
card, no nested anchors — which would be invalid and would break keyboard
navigation.
