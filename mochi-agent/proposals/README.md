# Proposals

Plans written for Thomas to decide on before anything is built: growth
plans, new features. Nothing in a proposal is built, posted or paid for
until Thomas approves it on its Issue.

- `pending/`: waiting for a decision
- `approved/`: approved; the work is filed as Task Issues
- `rejected/`: declined (never deleted)
- `completed/`: every Task Issue filed from it is closed

Filenames are `<YYYY-MM-DD>-<slug>.md`, dated the day the proposal was
first written (America/New_York). The full flow is in the shared handbook:
https://github.com/ptk-studio/ptk-studio/blob/main/projects/AGENTS.md
("Proposals").

This folder is outside `docs/`, so nothing here is published to the site.
